# ai-supply-chain

AI-powered supply chain risk intelligence system that uses Next.js, FastAPI, and Random Forest ML to detect, analyze, prioritize, and simulate supply-chain risks.

## Features

- AI Supply Chain Risk Analysis
- Random Forest Machine Learning
- Supplier Risk Detection
- Inventory Risk Analysis
- Transportation Risk Analysis
- Demand Risk Analysis
- External Risk Analysis
- Risk Score and Risk Level
- Scenario Simulation
- Mitigation Recommendations
- AI Risk Catalogue

## Technology Stack

- Next.js
- React
- TypeScript
- FastAPI
- Python
- Scikit-learn
- Random Forest
- Pandas
- NumPy
